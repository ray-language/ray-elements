# @raylang/elements

Web components for any app, with raylang extras (shadcn/ui + Mantine inspired).

Generated from [ray-elements](https://github.com/ray-language/ray-elements) (its `packages/elements`
directory): the components, their docs and the issues are there.

```
import "@raylang/elements/tokens.css";
import "@raylang/elements";   // registers every <ray-*> element

<ray-button variant="light">Save</ray-button>
```
