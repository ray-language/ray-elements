# @ray-ds/elements

Web components for any app, with raylang extras (shadcn/ui + Mantine inspired).

Generated from [ray-ds](https://github.com/ray-language/ray-ds) (its `packages/elements`
directory): the components, their docs and the issues are there.

```
import "@ray-ds/elements/tokens.css";
import "@ray-ds/elements";   // registers every <ray-*> element

<ray-button variant="light">Save</ray-button>
```
